01 / Access control

Only the owner writes

The onlyOwner modifier checks msg.sender. Every account can read the counter, but only the owner can change it.

Try Account #1: the transaction should be rejected.

02 / Input validation

Bad values never land

require(newNumber <= 100) runs before storage is changed. Invalid input reverts, so the contract keeps its previous safe value.

Try setting 101 to see the rejection message.

03 / Audit trail

Every change is logged

Successful calls emit NumberChanged with the caller, old value, and new value. The event list below is read directly from the local chain.

Send a valid change and watch the history grow.
